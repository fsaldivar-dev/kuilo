# Stage-Gate (Robert Cooper)

## Qué es
Framework para llevar una idea de producto desde concepto hasta lanzamiento. Cada "gate" es un checkpoint donde se decide continuar, pivotar, o matar el proyecto.

## Cuándo usarla
Productos nuevos que necesitan validación en cada etapa. Evita invertir en algo que no tiene mercado.

## Etapas

### 1. Discovery
Investigar el mercado y los usuarios. No asumas — observa y pregunta.
**Documentos:** User Research, Market Analysis

### 2. Scoping
Definir quién es el usuario y qué problema tiene. Crear arquetipos concretos.
**Documentos:** Personas, Journey Map

### 3. Business Case
Escribir el PRD: qué construir, para quién, por qué ahora, y cómo medir éxito.
**Gate:** ¿El PRD tiene hipótesis medibles? ¿El roadmap es realista?
**Documentos:** PRD, Roadmap

### 4. Development
Construir en sprints. El scope viene del PRD — no se agregan features mid-sprint.
**Documentos:** Sprint Plan, Prototipos

### 5. Validation
Probar con usuarios reales. Si no pasa usability testing, no lanza.
**Gate:** ¿Los test reports muestran que los usuarios completan las tareas?
**Documentos:** Test Reports, Usability Tests

### 6. Launch
Go-to-market. Activar canales, publicar release notes, monitorear métricas.
**Gate:** ¿Legal aprobó? ¿Canales están listos? ¿Monitoring está configurado?
**Documentos:** Launch Plan, Release Notes

## Fuente
