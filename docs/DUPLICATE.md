# Duplicar Pagina

Crea una copia exacta de un documento con todo su contenido.

## Uso

- Click en el icono de copiar (dos hojas) junto a cualquier pagina en el sidebar
- Se crea un nuevo documento con el titulo "[nombre] (copia)"
- El contenido (bloques, metadata) se copia completo
- El documento se abre automaticamente en el editor

## Casos de uso

- Usar un documento existente como template personal
- Crear variaciones de un PRD o RFC
- Hacer backup manual de un documento antes de editar
