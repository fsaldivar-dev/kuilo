# Charts y KPIs

Kuilo incluye gráficas interactivas con [Recharts](https://recharts.org/).

## Insertar

`/chart` o botón `+` → Chart

## Tipos de gráfica

- **Bar** — barras verticales
- **Line** — líneas de tendencia
- **Area** — áreas con relleno
- **Pie** — distribución circular

## Editar datos

1. Click en **"Datos"** para abrir la tabla de edición
2. Edita valores inline (nombre + valor numérico)
3. Agrega/elimina filas con `+` y 🗑️
4. La gráfica se actualiza en tiempo real

## Personalización

- **Título** — input en el header del bloque
- **Color** — color picker para cambiar el color de la gráfica
- **Tipo** — selector para cambiar entre bar/line/area/pie

## Export

En Markdown se exporta como bloque Mermaid `xychart-beta` (bar/line) o `pie`.
