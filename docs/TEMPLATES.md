# Templates

Kuilo incluye templates profesionales para documentación técnica y de negocio.

## Templates de bloque

Insertables desde `/` o el botón `+`:

| Template | Uso |
|---|---|
| **PRD** | Product Requirements Document |
| **RFC / ADR** | Propuesta técnica o decisión de arquitectura |
| **Meeting Notes** | Notas de reunión con agenda y action items |
| **Sprint Plan** | Sprint con capacity, backlog y retro |
| **API Spec** | Documentación de API con endpoints pre-armados |
| **Runbook** | Guía de operaciones con troubleshooting |

## Templates de proyecto

Generados por el **Project Wizard** con contenido guiado:

### Negocio
- **Lean Canvas** — 9 secciones del modelo de negocio
- **Modelo de pricing** — planes, competencia, unit economics

### Cliente
- **Customer Persona** — quién es, qué necesita, por qué se iría
- **Customer Journey** — descubrimiento → activación → retención → referencia

### Producto
- **Roadmap** — ahora / después / futuro
- **PRD** — problema, user stories, alcance, métricas

### Operaciones
- **Manual de operaciones** — apertura, operación, cierre
- **Checklist diario** — mañana, tarde, cierre

### Marketing
- **Plan de marketing** — objetivo, audiencia, canales, presupuesto, calendario
- **Canales de adquisición** — actuales, por probar, qué funciona, qué no

### Técnico
- **Stack técnico** — frontend, backend, DB, infra
- **API Spec** — endpoints con el bloque visual
- **Runbook** — descripción, incidentes, rollback

### Legal
- **Aviso de privacidad** — estructura LFPDPPP (México)
- **Términos y condiciones** — servicio, pagos, ley aplicable

### Franquicia
- **Manual de franquicia** — ubicación, inversión, capacitación
- **Checklist de apertura** — legal, local, personal, sistemas, marketing

### Bitácora
- **Bitácora del proyecto** — registro semanal: bien, mal, aprendí
