# Editor de bloques

Kuilo usa un editor visual basado en [Tiptap v3](https://tiptap.dev/) con soporte completo de Markdown.

## Bloques disponibles

### Texto
- **Headings** H1-H4
- **Paragraphs** con texto rico (bold, italic, underline, strike, code)
- **Superscript / Subscript**
- **Color highlight** multicolor
- **Links** con auto-linking de URLs

### Listas
- **Bullet list** — viñetas
- **Ordered list** — numeradas
- **Task list** — checkboxes interactivos
- **Toggle list** — bloques colapsables

### Contenido
- **Blockquotes** con borde lateral
- **Code blocks** con syntax highlighting (30+ lenguajes)
- **Tables** editables con resize de columnas
- **Images** con upload drag & drop
- **Horizontal rules** / dividers
- **Columns** layout (2-3 columnas)
- **Emoji shortcodes** — `:rocket:` → 🚀

### Callouts / Admonitions
5 tipos compatibles con GitHub Flavored Markdown:
- **Note** (azul) — información complementaria
- **Tip** (verde) — consejo o buena práctica
- **Important** (morado) — información crítica
- **Warning** (naranja) — advertencia
- **Caution** (rojo) — riesgo de error

### Ecuaciones
- **KaTeX** — bloques de ecuaciones LaTeX con renderizado en tiempo real

## Slash Commands

Escribe `/` para insertar cualquier bloque. Busca por nombre o keyword.

## Toolbar

La toolbar fija incluye todos los formatos de texto + el botón `+` que abre un menú con todos los componentes organizados por categoría.

## Bubble Menu

Al seleccionar texto aparece una toolbar flotante con las opciones de formato más usadas.

## Drag Handle

Cada bloque tiene un handle para reordenar arrastrando.
