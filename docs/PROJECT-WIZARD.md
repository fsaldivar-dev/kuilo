# Project Wizard

Wizard guiado para crear proyectos de documentación completos.

## Acceso

Sidebar → **Nuevo proyecto**

## Pasos

### 1. Proyecto
- Nombre del proyecto
- Descripción breve
- **Elegir carpeta** — file picker con opción de crear nueva carpeta

### 2. Tipo (presets)
- **Proyecto completo** — todas las áreas
- **App / Software** — producto + técnico + cliente
- **Startup** — negocio + producto + marketing + legal + bitácora
- **Franquicia** — operaciones + franquicia + negocio + cliente
- **Personalizado** — elige tú

### 3. Áreas (9 disponibles)
| Área | Documentos que crea |
|---|---|
| 💼 Negocio | Lean Canvas, Modelo de pricing |
| 👤 Cliente | Customer persona, Customer journey |
| 📦 Producto | Roadmap, PRD inicial |
| 🔧 Operaciones | Manual de operaciones, Checklist diario |
| 📣 Marketing | Plan de marketing, Canales de adquisición |
| ⚙️ Técnico | Stack técnico, API Spec, Runbook |
| ⚖️ Legal | Aviso de privacidad, Términos y condiciones |
| 🏪 Franquicia | Manual de franquicia, Checklist de apertura |
| 📝 Bitácora | Bitácora del proyecto |

### 4. Backup (opcional)
- URL del repositorio Git
- **"Crear token en GitHub"** — abre GitHub con formulario pre-llenado
- Token se pega en el wizard
- Al crear: init + commit + push automático

### 5. Crear
- Resumen de todo lo seleccionado
- Click en **Crear proyecto** genera los paquetes y documentos

## Contenido guiado

Cada documento generado incluye:
- 💡 **¿Por qué?** — explica la importancia de cada sección
- 📝 **¿Qué escribir?** — instrucciones concretas
- ❗ **Ejemplo** — texto real que puedes copiar y adaptar

## Documento "Empieza aquí"

Se crea automáticamente con:
- Lista ordenada de TODOS los documentos como checklist
- Orden de llenado recomendado (Lean Canvas primero)
- Tips de uso
