# Command Palette (Cmd+K)

Acceso rápido a cualquier acción o documento desde el teclado.

## Uso

- **Mac**: `Cmd+K`
- **Windows/Linux**: `Ctrl+K`
- **Escape** o click fuera para cerrar

## Búsqueda

Escribe para filtrar por título de página o nombre de acción. Matchea por título y keywords.

## Comandos disponibles

### Navegación
- Todas las páginas del vault (organizadas por paquete)

### Acciones
| Comando | Keywords |
|---|---|
| Nuevo paquete | crear, package, paquete |
| Nuevo proyecto | proyecto, wizard |
| Conectores AI | mcp, claude, cursor, ai, backup, git |
| Exportar libro PDF | pdf, libro, export |
| Publicar en web | publish, web, html, sitio |
| Abrir carpeta del vault | folder, carpeta, explorador |
| Cambiar vault | vault, cambiar, directorio |

## Teclado
- `↑` `↓` — navegar
- `Enter` — ejecutar
- `Escape` — cerrar
