# Atajos de Teclado

Panel de referencia con todos los atajos disponibles.

## Abrir

- **Cmd+/** (Mac) o **Ctrl+/** (Windows/Linux)

## Atajos disponibles

### General
| Atajo | Accion |
|---|---|
| Cmd+K | Command palette |
| Cmd+/ | Panel de atajos |
| Cmd+W | Cerrar tab activo |
| Ctrl+` | Toggle terminal |

### Editor
| Atajo | Accion |
|---|---|
| Cmd+B | Negrita |
| Cmd+I | Cursiva |
| Cmd+U | Subrayado |
| Cmd+E | Codigo inline |
| Cmd+Shift+X | Tachado |
| Cmd+Z | Deshacer |
| Cmd+Shift+Z | Rehacer |

### Bloques
| Atajo | Accion |
|---|---|
| / | Slash commands (insertar bloque) |
| @ | Mencionar pagina (wiki link) |
