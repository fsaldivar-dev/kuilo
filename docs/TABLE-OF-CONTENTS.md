# Table of Contents Block

Bloque que genera automaticamente un indice de contenido basado en los headings del documento.

## Insertar

Escribe `/toc` en el editor para insertar el bloque.

## Comportamiento

- Se genera automaticamente desde los headings (H1, H2, H3) del documento
- Se actualiza en tiempo real al agregar o quitar headings
- Click en cualquier entrada → scroll al heading correspondiente
- Se exporta como lista de links en Markdown y HTML

## Uso recomendado

- Documentos largos con multiples secciones
- PRDs, RFCs, y manuales de operaciones
- Cualquier doc con mas de 5 headings
